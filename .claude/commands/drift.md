The code and the document disagree: $ARGUMENTS

One of them is a bug. Decide which.

Argue both sides in under 150 words, then commit to one.

- If the document is wrong, rewrite the specific lines.
- If the code is wrong, name the fix and the invariant it restores.

Do not do both. Do not resolve it by softening the document's language until it stops
contradicting the code — a constraint that nobody could violate is not a constraint, and
hedging is how a document with teeth degrades into advice.
