# AI operating surfaces

Home uses the supplied GildOps dashboard composition: compact toolbar, four KPI cells, two-thirds operating column, one-third contextual rail, dense tables and management links. `destinations.png` is an image-generated reference sheet for the substantial destinations. Its illustrative metrics, models and green states are not product data or runtime claims.

| Control | Destination and behavior |
|---|---|
| KPI | URL-filtered collection/activity |
| Search, status, channel, date | URL-backed filter |
| New Agent | Drawer; creates Draft then opens dedicated editor |
| Agent row | Workbench |
| Workbench sections | Persistent local editor selection; edits retained and recoverable after reload/back navigation |
| Save | Optimistic-concurrency checked draft write |
| Delete | Unused drafts/disabled configurations only; historical evidence retained |
| Publish / Disable | Confirmed lifecycle action; immutable version or disable |
| Version | Inspect immutable configuration; deployment explicitly selects version |
| Channel | Deployment configuration drawer with channel-specific policy |
| Website preview | Existing public widget, actual published website |
| Knowledge | Published site selection; draft association and version snapshot |
| Tools | Allowlisted canonical read tools; approval policy |
| Test | Safe preview playground; no tools, business writes or external sending |
| Evaluation | Human verdict on recorded response and expected criterion |
| Activity | Authorized run inspector or Communications-owned conversation |
| Handoff | Communications Inbox |
| Operator chat | Existing persistent global Agent rail |
| Configure | Agent configuration, never provider credentials |

Desktop editors use left navigation, central form and right readiness inspector. Tablet stacks the inspector. Phone uses a section selector and one central editor pane. Missing usage remains unavailable, never zero. Unsupported channel runtimes cannot be enabled.
