# app/auth verifies a human caller's Supabase access token against the project's JWKS rather
# than hand-rolling asymmetric-signature verification. PyJWT's PyJWKClient already caches fetched
# keys and re-fetches on an unrecognised key id, which is what key rotation needs -- see
# app/auth/supabase.py. The [crypto] extra pulls in cryptography for RS256/ES256 verification.
PyJWT[crypto]==2.13.0

# beside it -- the one a local model arrives through -- needs no library at all.
#
# It brings `httpx2`, which is a different distribution from the `httpx` pinned above rather than
